# 帰らずの森 — 五つの鍵

承認された少女と森林素材を使った、スマホ縦持ち向けのThree.js脱出ゲーム。試作一区画を4エリアへ拡張。旧版と `prototype-v2` は保持。

## 起動
`npm install` → `npm run dev` → http://localhost:5176/

`npm run build` で相対URLの静的ビルドを `dist/` に生成。`npm run preview` は http://localhost:4176/ 。GitHubへのコミット・push・公開は行っていない。

## 目的・操作
「灯籠の小径」「水鏡の池」「杉影の参道」「奥社」の4エリアに散らばる鍵を5つ集め、入口の鳥居を調べて脱出する。各エリアに必ず1個以上。最初の鍵を拾って12秒後、鬼が遠くから現れる。任意の手帳は3つ。

- 左スティック / WASD / 矢印：8方向移動。
- 右下の走るボタン長押し / Shift：スタミナ走行。
- 右下の向き固定 / F：向きを維持して低速移動。走行不可。
- 右下の灯り：懐中電灯ON/OFF。消灯で発見距離を短くできる。
- 調べる / E / Space：近くの鍵・手帳・入口。
- 道案内 / 上部の一時停止 / Esc：時間を止め、4エリアの現在地・取得数を確認。音・画質設定もここに集約。

音は初期OFF。標準画質は深度を使う控えめな被写界深度と影、軽量画質はそれらを無効化しピクセル比を1にする。タブを離れると自動停止。鍵は再挑戦ごとに再抽選。検証用に `?seed=1` のような固定配置を指定した場合のみ、再挑戦も同じ配置になる。

## 表現と再利用
承認済みの樹木・草石・和風小物・少女を継続使用。カメラを低くして追従を追加。石段・祠の台座・岩に立体形状を使い、懐中電灯の投影影、遮蔽で切れる照射、漂う霧、ビネット、深度ぼかしを組み合わせた。少女に重なる手前の木は透過して視認性を保つ。

少女8方向×8コマ、鬼8方向×7コマを提供シートから抽出。入力・合成音は一区画版から再利用。依存はThree.js 0.180.0、Vite 7.3.6のまま。追加のライブラリ・画像生成はなし。[出典](public/CREDITS.md)を同梱。

## 残る限界
背景の大部分は平面スプライト。全面的な立体建築・体積霧ではない。細かな装飾物全てに独立した衝突は持たせていない。ブラウザのスマホサイズ検証は実機性能や初見の体感難度を保証しない。初見約10分という目標は人による試遊が未実施のため未検証。今回の最短経路ボットは1分前後で脱出できる。
